User Requirements:
1. GENERAL USER REQUIREMENTS
These apply to all users:
 provide a secure login for users.
 support role-based access (Admin, Teacher, Student).
 user-friendly interface.
 ensure data security and privacy.
 allow users to logout safely.
2. ADMIN USER REQUIREMENTS
The Admin is responsible for system management.
Functional Requirements
 allow the admin to login.
 allow the admin to add, update, and delete students.
 allow the admin to add, update, and delete teachers.
 allow the admin to create subjects.
 allow the admin to assign subjects to teachers.
 allow the admin to view user details.
3. TEACHER USER REQUIREMENTS
The Teacher manages attendance.
Functional Requirements
 allow the teacher to login.
 allow the teacher to view assigned subjects and classes.
 allow the teacher to select date, class, and subject.
 allow the teacher to mark attendance (Present/Absent).
 The system shall allow the teacher to view attendance reports.
4. STUDENT USER REQUIREMENTS
The Student views attendance details.
Functional Requirements
 allow the student to login.
 allow the student to view subject-wise attendance.
 allow the student to view overall attendance percentage.
 allow the student to view attendance history.

-- 4 of 9 --

5. ATTENDANCE MANAGEMENT REQUIREMENTS
 store attendance with date and time.
 associate attendance with student, teacher, and subject.
 allow retrieval of daily, weekly, and monthly attendance.
 maintain historical attendance records.
6. DATABASE & SYSTEM REQUIREMENTS
 store data in a MongoDB database.
 ensure data consistency.
 support CRUD operations.
 handle multiple users simultaneously.
7. SECURITY REQUIREMENTS
 encrypt passwords.
 use JWT authentication.
 restrict access based on user roles.
 protect against unauthorized access.
